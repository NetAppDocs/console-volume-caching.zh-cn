:hardbreaks:
:allow-uri-read: 
:icons: font

[role="lead"]
如果您只是想快速找到问题的答案，此常见问题解答可以为您提供帮助。

*卷缓存 URL 是什么？*在浏览器中输入网址： https://console.netapp.com/["https://console.netapp.com/"^] 访问BlueXP控制台。

使用卷缓存需要许可证吗？不需要NetApp许可证文件 (NLF)。

如何启用卷缓存？卷缓存无需任何启用操作。卷缓存选项会自动显示在NetApp Console左侧导航栏中。
